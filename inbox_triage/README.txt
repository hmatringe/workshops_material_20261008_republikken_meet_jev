Tri de boite mail (cas Republikken)

Questions sur chaque mail, en un appel : type (choice), urgence (score), besoin d'un humain (noul).
Entree : mails fictifs d'une communaute (adhesion, evenement, salle, spam, plainte).
Sortie : file triee, les incertains vers un humain.

A definir ensemble
- Le prompt : les options du choice, l'echelle du score, les criteres.
- L'app : page de demo, boite de reception, decision par mail.
- L'experience Sonnet vs Jev : dataset, taille, metriques.
